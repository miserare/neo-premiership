# Bundled fonts

`jost-variable.woff2` is the latin subset of [Jost](https://github.com/indestructible-type/Jost),
a geometric sans in the Futura/Erbar tradition, served from Google Fonts as a
variable font (weight axis 100-900).

It is self-hosted rather than loaded from the Google Fonts CDN so the first
paint doesn't depend on a third-party request.

alongside the font file.
